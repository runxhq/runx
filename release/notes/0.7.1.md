# Runx CLI 0.7.1

Runx 0.7.1 adds an exact-version CVE audit and a local operator inbox, and
resumes runs paused on approval gates.

## Added

- An exact CVE audit skill: a governed audit of exact dependency versions
  against OSV, with fixtures and packet schemas.
- An operator inbox skill backed by the generic data store: unbound local
  sources use SQLite, page forward through events, keep explicit dispositions
  and reopen only for newer external work.
- `runx login` can take the signed-in GitHub CLI identity.
- An Operator Skills index mapping common operations patterns to the shipped
  skills.

## Fixed

- A run paused on an approval gate resumes.
- Provider host paths are preserved, and operator workflows execute what they
  describe.
- Operator state storage was hardened, and transition output stays bounded.
