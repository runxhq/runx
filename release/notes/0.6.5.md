# Runx CLI 0.6.5

Runx 0.6.5 scaffolds native skill packages.

## Changed

- `runx new` generates a native skill package. The `@runxhq/create-skill`
  package behind `npm create @runxhq/skill` is gone.

## Fixed

- Publishing authenticates against the hosted API.
- The release checks that every package carries the CLI's version.
