# Runx CLI 0.6.15

Runx 0.6.15 runs skills on Windows and moves the schema authority to runx.ai.

## Changed

- The thread mirror supports a full reconcile mode.

## Breaking changes

- Contract schema ids moved from `https://schemas.runx.dev/` to
  `https://schemas.runx.ai/`. A consumer that matches schema `$id`s reads the
  new host.

## Fixed

- Skills run on Windows: content-addressed receipts are stored under
  platform-safe file names while keeping the public `sha256:` id, and
  `/usr/bin/env` runners are shimmed where Unix paths do not exist.
- An operator can pass an explicit local environment to a run.
