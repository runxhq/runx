# Runx CLI 0.5.1

Runx 0.5.1 fixes the npm package so it installs outside the workspace.

## Fixed

- Workspace dependencies are rewritten to published versions when the CLI is
  packed for npm, so `npm install @runxhq/cli` resolves every dependency.

## Notes

Published to npm on 2026-04-24. It was the last release of the TypeScript CLI;
0.6.0 is the native runtime.
