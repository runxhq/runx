# Runx CLI 0.4.1

Runx 0.4.1 is the first release of `@runxhq/cli` on npm. It is the
TypeScript CLI that later became the native runtime: it runs governed skills,
writes receipts, and installs skills from the registry.

## Highlights

- The governed dogfood skill catalog, run through `runx skill` with receipts
  for every run.
- An `issue-to-pr` lane that takes an issue or repository snapshot through
  scafld specs, review and a pull request, with harness cases at each stage.
- Registry installs from the hosted registry and from GitHub sources, with an
  HTTP-cached registry store and registry references inside chains.

## Added

- `runx history` filters: `--skill`, `--status`, `--source`, `--since` and
  `--until`.
- Trainable receipt exports.
- `RUNX_PRODUCTION=1`, which fails closed with a clear error when a run is left
  unresolved.
- Skill version fields, catalog metadata for skills and chains, and harness
  cases across the first-party skills.

## Changed

- Skill profiles are versioned by package shape, and upstream bindings are
  declared beside them.
- The internal execution model is a graph.

## Fixed

- Harness tool runs work in a temporary directory, and scafld honors
  `RUNX_CWD`.
- A run missing a required input writes its journal before asking for it.
