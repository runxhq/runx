# Runx CLI 0.6.3

Runx 0.6.3 brings the first community contributions into the catalog and
tightens sandbox and credential handling across the runtime.

## Added

- A governed Open-Meteo weather skill, consolidated into one global weather
  provider.
- A metadata harness fixture for `web-fetch`.

## Changed

- The README was rewritten as a short overview.

## Fixed

- A step that fails always reports a message.
- The sandbox enforcement a run asks for is preserved through graphs and the
  harness, and the operator's sandbox override reaches the runtime.
- Skill authoring keeps a POSIX `RUNX_CWD` intact on Windows.

## Security

- Skill authoring refuses a repository path that escapes through a symlink.
- A local tool's credentials are isolated from other tools.
