# Runx CLI 0.6.17

Runx 0.6.17 lets the registry operator repair a published skill and isolates
the publish harness.

## Added

- Governed admin repair for a published skill, with hosted admin skill links.
- Guidance for writing skills for the catalog.

## Fixed

- The publish harness runs in an isolated environment.
- A harness expectation failure includes the run's diagnostics.
- The dependency audit runner no longer depends on `undici`.
- Orphaned GitHub threads are retired, and linked threads are refreshed in
  place.
