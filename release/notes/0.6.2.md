# Runx CLI 0.6.2

Runx 0.6.2 makes each run an act with its own receipt, opens the hosted
registry to self-serve publishing, and binds a published package's files to
its signed manifest.

## Highlights

- Every run is an act. Governed turns seal domain-act receipts, credentials a
  run receives are recorded as authority grants, and graphs can run agents
  inline.
- `runx login` and public API access, with a self-serve registry surface for
  publishing skills.

## Changed

- Step sealing goes through one entry point for skills, graph steps and agent
  acts.
- A skill's declared `act:` block is parsed and validated when the skill loads.

## Fixed

- A credential is resolved only with its delivery observation, so a credential
  cannot reach a step without the observation that proves where it went.
- Published packages persist every installable file, run their publish harness
  from the packaged files, and publish only the root runners they consume.

## Security

- Skill execution boundaries were hardened.
- A hosted skill upload is size- and shape-constrained, and its package files
  are bound in the signed manifest.
- Source signing is separate from first-party trust, and the official manifest
  trust anchor was rotated.
