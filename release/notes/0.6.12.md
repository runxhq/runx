# Runx CLI 0.6.12

Runx 0.6.12 adds operations skills for support and business work and aligns the
registry install commands.

## Added

- A support triage reply skill, with its dogfood evidence.
- A business operations skill and the ops desk catalog it composes.

## Changed

- Registry install commands print one form, and the README states the active
  CLI install channels.

## Fixed

- Thread lifecycle intents that open an issue are handled.
- The release skill's validation fixtures and the send plan's packet schema
  were repaired.
