# Runx CLI 0.6.14

Runx 0.6.14 makes graph steps address each other only through declared
contracts and attenuates authority as it passes down a graph.

## Highlights

- Contract-only step output addressing: a step reads another step's result only
  through the outputs that step declares.
- Authority attenuation: a run can mint a narrower authority from the one it
  holds, and a request for anything outside the parent's authority fails
  closed.
- The agency skills core: hosted harness runs seal a verified attenuation,
  spend and refund runners accept a ceiling input, and an agent's approval
  reason is carried onto the sealed receipt.

## Changed

- An artifact carries its value once, under `.data`, instead of a double
  wrapper.
- The thread mirror is a generic reconcile engine: it diffs a desired thread
  state against live GitHub and applies only the difference, reading each
  issue once.
- Rust module boundaries and the workspace were cleaned up.

## Fixed

- An empty managed-agent turn is sampled again before the run fails closed.
- Governed outbound packet addressing was corrected, and terminal-step adoption
  hardened.

## Breaking changes

- A graph context edge binds a step's declared output or artifact packet,
  never its base fields (`stdout`, `stderr`, `status`, `raw`); the parser
  refuses one that does when it validates the graph.
- Graph references to artifacts read `.data`; the double-wrapped form is gone.
