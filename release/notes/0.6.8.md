# Runx CLI 0.6.8

Runx 0.6.8 adds two community skills, short flags for common options and named
credential profiles, and requires agent steps to declare what they return.

## Added

- A dependency CVE audit skill and a structured extraction skill.
- Short flags: `-j` for `--json` and `-R` for `--receipt-dir`.
- `runx skill --credential-profile` selects a named local credential profile,
  and graph steps can name one.
- Portable category metadata for skills, and a `system` catalog audience in the
  registry.
- The open-web fetch transport sends a browser profile.

## Changed

- An agent step must declare its outputs; an undeclared output is refused.
- Execution profiles are held to the supported YAML subset, and scafld lanes
  require a minimum runner version.
- The managed agent's HTTP timeout is longer, and graphs use it too.

## Fixed

- Governed continuation checks were restored.
- A partial agent configuration is diagnosed instead of failing later.
- HTTP transport diagnostics are preserved, and a receipt publish scope error
  says what is missing.
