# Runx CLI 0.5.0

Runx 0.5.0 adds skill authoring from the CLI and reorganizes the workspace into
clear package boundaries.

## Added

- A `create-skill` bootstrap for authoring a new skill package.
- Hosted schemas owned by the contracts package, and a deep research brief
  skill.
- The CLI package exports its own metadata.

## Changed

- The workspace was collapsed into fewer, modular packages; the runner, doctor,
  history and connect commands each have their own module.
- Local runner governance and input handling are separate concerns.

## Fixed

- Thread message comments can be edited.
