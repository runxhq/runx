# Runx CLI 0.6.13

Runx 0.6.13 adds the governed data plane: contracts and fixtures for skills
that read and write a data store under the runtime's admission.

## Added

- Governed data-plane contracts and fixtures.

## Changed

- The CLI's skill execution and export surfaces were hardened, and the official
  skill catalog's coverage was refreshed.

## Fixed

- `runx resume`, `runx doctor` and skill execution were restored after the
  data-plane change, and fixture thread adapters never reach live GitHub.
