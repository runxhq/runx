# Runx CLI 0.7.0

Runx 0.7.0 shows the operator what a skill run will act on before it runs, and
lets the operator bind the run to that exact context.

## Highlights

- Before a skill runs, runx prepares the operator context it will act on (the
  skill, its runner, tools, boundaries and inputs) and prints a summary with
  its digest. `runx skill --approve-operator-context <digest>` runs only when
  the prepared context matches that digest, and `--full-operator-context`
  prints all of it.

## Changed

- The release generates the winget manifest set for each installer and submits
  it to winget.
- The CLI release runbook points at the workspace release status and is
  constrained to the governed publish flow.
