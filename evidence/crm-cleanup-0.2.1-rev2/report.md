# crm-cleanup: the cleanup that executes its writes

A CRM that rots after every call is a pipeline lying to itself. This delivery publishes `antheducation/crm-cleanup`, a runx skill that reads the current CRM records from a real source at run time, reconciles a call transcript against them deterministically, and executes the decided field updates through a transport that seals before/after evidence in the same run. The read -> decide -> write loop is proven in one sealed dogfood receipt, not an inert proposal object.
